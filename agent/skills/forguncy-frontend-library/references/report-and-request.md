## 维护本指南（本技能的知识源）

活字格前端扩展机制变化后，同步检查：

- ZIP 和单文件大小限制。
- Manifest schema。
- 是否开始部署额外资源文件。
- 是否支持 ESM、Import Map、异步初始化或依赖声明。
- ReactCellType 宿主 React/ReactDOM 版本。
- CodeEditor 的 Monaco TypeScript 版本和类型注入方式。
- MCP API 名称、参数和权限模型。

平台实现与文档冲突时，以当前产品实际校验和运行行为为准，并修订对应参考件。不要让 AI 根据过期文档猜测。
